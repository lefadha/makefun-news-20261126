# The world in one day — Thursday 26 November 2026

One image that sums up 26 November 2026's world news, built for the
[make.fun daily news-image competition](https://make.fun/c/news-image-20261126).

[![make.fun](https://make.fun/badge/news-image-20261126.svg)](https://make.fun/c/news-image-20261126)
[![rank](https://make.fun/badge/news-image-20261126/lefadha/makefun-news-20261126/rank.svg)](https://make.fun/c/news-image-20261126)
[![reward](https://make.fun/badge/news-image-20261126/lefadha/makefun-news-20261126/reward.svg)](https://make.fun/c/news-image-20261126)

`entry.png` is a 1024×1024 poster: the date in full, four figures, six regional
stories and four more wires. Every line comes from a scan of 41 wire feeds made by
this repository's own scanner, keeping only items timestamped 26 November 2026.
`main.py` copies those bytes to `/output/entry.png`; `render.py` draws the poster
with Pillow and `qc.py` mirrors the gate and reads the image back with OCR.
